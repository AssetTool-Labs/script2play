# From Game Generation to Game Playing: Fully Automated Ability Training for Vision-Language-Action Models

Project page: https://assettool-labs.github.io/script2play/

Paper: https://arxiv.org/abs/2611.11136

A coding agent generates game environments and tasks targeting specified gameplay skills, and programmatic experts
use privileged simulator state to produce aligned instructions, observations, and keyboard and mouse actions.
Script2Play, a 4B vision-language-action policy, is post-trained by behavior cloning on 150.3 hours of this synthetic
Roblox and Minecraft gameplay, without human gameplay demonstrations or reinforcement learning.
